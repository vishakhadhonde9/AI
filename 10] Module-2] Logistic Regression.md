# Logistic Regression -
- Logistic Regression is a supervised machine learning algorithm used for classification problems, where the goal is to predict the probability that an observation belongs to a particular class or category.
- Despite its name containing the word "Regression", Logistic Regression is primarily used for classification problems, especially binary classification.
- Examples:
    - Spam or Not Spam
    - Fraud or Not Fraud
    - Pass or Fail
    - Disease Present or Disease Absent
